Визуальный интерфейс Орио

Спек · 2026-05-27 · статичный HTML, регенерируется скриптом

Задача: Статичная HTML-страница — "лицо" ассистента Орио. Показывает архитектуру системы, ссылки на ключевые компоненты и состояние памяти. Генерируется скриптом из реальных файлов (facts.md, current_state.md, CLAUDE.md) и сохраняется локально. Открывается в браузере как дашборд.

Варианты дизайна

Вариант 1 — Mind Map
Орио в центре. Вокруг — узлы: Проекты, Память, Скиллы, Инфраструктура. Клик на узел — раскрывает детали.
[Орио] / | \ [Проекты] [Память] [Скиллы] | | | reg-rag facts.md /spec wta decisions /dreaming ... handoffs ...
  • Наглядная структура
  • Визуально интересно
  • Сложно генерировать
  • Плохо масштабируется
Вариант 2 — Панели (рекомендую)
Три колонки: Архитектура (блоки с компонентами и стрелками), Память (последние факты, handoff), Ссылки (проекты, скиллы, файлы).
┌─ Архитектура ─┬─ Память ──┬─ Ссылки ──┐ │ [Telegram] │ facts.md │ Проекты │ │ ↓ │ • Орио │ reg-rag │ │ [Claude Code] │ • VPS │ wta │ │ ↓ │ ───────── │ ───────── │ │ [Скиллы] │ handoff │ Скиллы │ │ [Память] │ 2026-05-27│ /spec │ │ [Проекты] │ │ /dreaming │ └───────────────┴───────────┴───────────┘
  • Легко генерировать
  • Вся инфо на экране
  • Просто обновлять
  • Менее "живой"
Вариант 3 — Профиль
Страница-профиль: аватар/лого Орио, описание, список проектов карточками, блок памяти, последний handoff.
╔══════════════════════╗ ║ 🤖 О Р И О ║ ║ AI-ассистент Петра ║ ╚══════════════════════╝ Активные проекты: [reg-rag ✅] [WTA 🔄] [emigr 📋] Последний handoff: 2026-05-27 "YouTube Knowledge Base..." Память: 42 факта · 12 решений
  • Красиво
  • Легко читать
  • Мало деталей архитектуры

Критерии приёмки

  • Страница открывается в браузере без сервера (file://)
  • Показывает архитектуру: компоненты системы и связи между ними
  • Показывает память: последние факты из facts.md
  • Показывает состояние: активные проекты из current_state.md
  • Содержит ссылки на ключевые файлы (кликабельные file:// пути)
  • Генерируется скриптом (Python) из реальных md-файлов
  • Скрипт запускается без параметров: python3 ~/scripts/gen_dashboard.py
  • Результат: ~/knowledge/orio-dashboard.html
  • Без внешних зависимостей (CSS встроен)
